# RawAndUgly

Welcome to the most gloriously unserious repo on the planet.

This is the place where weird binaries go to live, and where the code is only as organized as my mood that day.

## What this is

- A goofy scratchpad for random stuff.
- A home for binaries I do not want in a normal repo.
- Not meant to be taken seriously. Ever.

## Contents

- `bin/` or `build/` style nonsense may appear.
- Random executables, temporary hacks, and things that should probably be in a dumpster.
- Probably some terrible scripts and half-baked ideas.

## Rules

1. Do not expect structure.
2. Do not expect documentation.
3. Do expect a little chaos.

## Disclaimer

This repo exists mostly for me to stash messy binaries and goof off. If you're reading this, congratulations: you found the junkyard.

Have fun, or don't. It's RawAndUgly.
